# 路径重命名功能增强

## 新增功能

### 1. 输出目录层级控制 (`maxOutputDepth`)
- **功能描述**：可配置输出文件保留的最大目录层数，`pathing/` 根目录不计入层数

- **配置方式**：在 `settings.json` 中设置 `maxOutputDepth` 参数
  - 留空或 `999`：保留原始层级（默认）
  - `1-N`：限制输出目录为 N 层
  
- **示例**：

  ```
  原路径：pathing/食材与炼金/「冷鲜肉」/「冷鲜肉」[迪希雅]@密柑魚/file.json 
  配置：maxOutputDepth = 2 
  输出：rename/食材与炼金/「冷鲜肉」/冷鱼肉-xxx.json
  ```

  ### 2. 基于内容校验码的去重机制
  - **功能描述**：在同一输出目录下，自动检测并跳过内容重复的文件
  - **校验逻辑**：
    - 使用 `generateContentCode(positions)` 生成坐标内容的哈希校验码
    - 校验码包含在文件名中（末尾 8 位 16 进制数）
    - 仅在同一输出目录下进行去重，跨目录文件不互相影响
  - **优势**：即使文件名不同，只要坐标内容相同就会被识别为重复文件

  ### 3. 材料名智能提取
  - **改进点**：`extractResourceNameFromPath` 函数现在返回 `{name, depth}` 对象
  - **匹配优先级**：
    1. 优先从目录结构中提取正式材料名（支持「」等特殊符号）
    2. 次选从文件名中提取（适配 `01-「冷鲜肉」-xxx.json` 格式）
  - **层级计算**：准确记录材料名所在目录层级，用于后续目录截断

  ## 代码优化

  - ✅ 增强参数校验：对 `maxOutputDepth` 配置进行有效性验证
  - ✅ 完善错误处理：补充缺失的 `catch` 块，统一异常日志格式

  ## 使用说明

  ### 配置文件更新
  在 `settings.json` 中新增配置项：

  ```JSON
  { "name": "maxOutputDepth", "type": "input-text", "label": "----------------------------------\n\n输出目录最大层数（留空表示保留原层级，默认：不限制）" }
  ```

  ### 运行流程
  1. 读取材料 CD 配置，收集正式材料名
  2. 解析传送点文件（基于 `tranPosition`）
  3. 遍历 `pathing/` 目录下的路径文件
  4. 对每个文件：
     - 提取材料名和层级信息
     - 生成坐标内容校验码
     - 匹配最近的传送点
     - 构建新文件名（包含校验码）
     - 检查当前输出目录下是否有重复校验码
     - 写入文件并记录校验码
  5. 输出统计信息

  ## 兼容性说明
  - ✅ 保持原有校验码生成逻辑不变
  - ✅ 保持原有传送点匹配算法不变
  - ✅ 向下兼容：未配置 `maxOutputDepth` 时行为与原版本一致
